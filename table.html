ダイニングテーブルからデスクまで。木目や節の表情をそのまま活かし、暮らしの中心になる一台をおつくりします。

ABOUT THIS FURNITURE

家族が集まる場所に、
ちょうどいいサイズを。

テーブルは、暮らしの中で最も長い時間を共にする家具のひとつです。

設置する部屋の広さやご家族の人数、使い方に合わせて、天板の形状・サイズ・脚のデザインを一つひとつ調整します。無垢材ならではの木目の美しさを活かし、一枚板から見せる仕上げまで、ご希望に沿ったご提案をいたします。

ダイニングテーブルはもちろん、在宅ワーク用のデスクや作業台としてのオーダーも承っております。

FEATURES

テーブルづくりで、
大切にしていること。

01 / SIZE

サイズのフルオーダー

設置スペースやご家族の人数に合わせて、幅・奥行き・高さを自由に調整。既製品では叶わないぴったりのサイズをご提案します。

02 / MATERIAL

樹種と一枚板の選択

オーク、ウォールナット、チェリーなど木目や色合いの異なる樹種からお選びいただけます。一枚板をお探しの方もご相談ください。

03 / FINISH

用途に合わせた塗装

木の質感を活かすオイル仕上げから、耐久性に優れたウレタン塗装まで、ご使用シーンに合わせて仕上げをお選びいただけます。
